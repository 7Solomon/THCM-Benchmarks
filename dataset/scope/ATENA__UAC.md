# ATENA/UAC

**Domain:** mechanical, 2D, quasi-static (pseudo-time)
**Fields:** displacement
**Creep:** none
**Damage:** compression softening, with an explicit localization band
**Output:** Normalised stress-strain curves for specimen heights h = 50, 100, 200 mm (Fig. 1-8), against Van Mier (1984). The point is size-independent post-peak response.
